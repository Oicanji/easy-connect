Easy Connect

v1.0.2

Automação de acesso às suas VMs com segurança! Um comando simples e você ou seu LLM já se conecta ao seu servidor, sem expor senhas ou credenciais para ninguém.

Windows

Instalador Pacote Código fonte
Requisitos
  • Windows 10 (1809 ou superior) ou Windows 11, 64 bits
  • Cliente OpenSSH do Windows
  • Para o instalador: permissão de administrador na primeira instalação

Linux

Instalador Pacote Código fonte
Requisitos
  • Python 3.11 ou superior
  • Cliente OpenSSH (openssh-client)
  • Ambiente gráfico para a interface (Qt/PySide6)

macOS

Indisponível
Instalador Pacote Código fonte
Requisitos
  • Pacote ainda não disponível para macOS

Agentes LLM (opcional)

Necessário utilização de CLI do respectivo agente baixado via irm/npm.

Totalmente opcional, você pode apenas pedir para o LLM ou ferramenta executar o comando EX:ssh-10-142-0-31 diretamente.
